Your Domain Is More Than a Web Address

A business domain can support many different services at the same time.

The same domain may be used for:

  • Your website
  • Business email

  • Cloud applications

Each service may be hosted by a different provider while still using the same domain.

What DNS Does

DNS directs Internet traffic associated with your domain.

Different DNS records can control different services.

Common examples include:

  • A and AAAArecords for website and server addresses
  • CNAMErecords for aliases and hosted services
  • MXrecords for email delivery
  • TXTrecords for verification and email authentication
  • SPF, DKIM, and DMARCrecords related to email
  • Records used by cloud platforms and third-party services

Most businesses do not need to administer these records themselves.

AmeriHost can manage the DNS configuration and coordinate changes when websites, email systems, or other services are moved.

Website and Email DNS Must Be Coordinated

Moving a website should not accidentally move or interrupt the company's email.

Likewise, changing an email provider should not interfere with the website.

This is why DNS changes need to be planned around all of the services using the domain.

Website DNS

  • Website hosting
  • Subdomains
  • Cloud applications
  • Redirects

Email DNS

  • Business email
  • Transactional email
  • Verification services
  • Other existing services

Before making significant DNS changes, AmeriHost can review records associated with:

  • Website hosting
  • Business email
  • Transactional email
  • Subdomains
  • Verification services
  • Cloud applications
  • Redirects
  • Other existing services

This allows the required records to be preserved while only the services involved in the project are changed.

Website Redirects

When website addresses change, redirects can send visitors and search engines from an old URL to the appropriate new location.

Redirects are particularly important during:

  • Website rebuilds
  • Page restructuring
  • Domain changes
  • Migration from older website platforms
  • Removal or consolidation of obsolete pages
  • Changes from legacy file extensions or URLs

AmeriHost can review existing website addresses and configure appropriate redirects as part of a migration or rebuild.

This can help preserve useful incoming links and reduce unnecessary 404 errors after a new site launches.

Subdomains

A subdomain allows a business to create additional addresses beneath its primary domain.

Examples might include:

  • portal.yourcompany.com
  • support.yourcompany.com
  • members.yourcompany.com
  • new.yourcompany.com

Subdomains can be used for applications, customer portals, development sites, support systems, or other services.

AmeriHost can configure the DNS records needed to connect subdomains to the appropriate destination.
