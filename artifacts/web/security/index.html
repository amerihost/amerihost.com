What Is Endpoint Security?

An endpoint is a computer or other device that connects to a business network or accesses business information.

For many small and midsize businesses, employee computers are among the most exposed parts of the technology environment.

Endpoint security is designed to help protect those devices from malicious or unauthorized software and other threats.

This can be particularly important for computers used for:

  • Business email
  • Accounting and financial information
  • Customer records
  • Cloud applications
  • Remote access
  • File sharing
  • Administrative functions
  • General Internet access

Protecting the endpoint adds another layer of security around the information and services employees use every day.

PC Matic Endpoint Security

AmeriHost offers PC Matic as an endpoint-security option for business computers.

Traditional antivirus products often focus on identifying software that is already known to be malicious.

PC Matic adds an application-allowlisting approach that focuses on determining which software is permitted to run.

With this type of protection, known and trusted applications can operate while unknown applications can be prevented from executing until they are classified or approved.

This prevention-oriented approach can help reduce exposure to new or previously unidentified malicious software.

Application Allowlisting

Application allowlisting establishes a set of software that is permitted to execute on a protected computer.

Rather than assuming an unknown program is safe until a threat is detected, an allowlisting system can prevent unfamiliar applications from running until they are determined to be trusted.

PC Matic applies this concept to applications and other executable activity on protected endpoints.

This can provide an additional layer of protection against threats that traditional detection methods may not yet recognize.

Protection Beyond Traditional Antivirus

No single security technology should be considered a complete cybersecurity strategy.

Endpoint protection works best as one part of a broader approach that can also include:

  • Secure passwords and authentication
  • Software updates
  • Appropriate user permissions
  • Email security
  • Reliable backups
  • Secure networks
  • DNS and website security
  • Employee awareness
  • Controlled remote access
  • Appropriate firewall configuration

AmeriHost can help clients understand where endpoint protection fits within the technology they already use.

Protection Against Unknown Applications

New threats may appear before traditional security products have complete information about them.

A prevention-based application-allowlisting approach can help by restricting unknown applications from executing rather than waiting until they have been identified as malicious.

Legitimate software that is not already recognized may require review or approval.

This is an important distinction from a security model based entirely on identifying known malware.

Script and Process Control

Cyberattacks do not always arrive as conventional executable programs.

Malicious activity can also involve scripts, macros, command-line tools, and legitimate applications being used in unintended ways.

PC Matic's business security platform includes controls designed to address executable files, scripts, processes, and other application activity.

These additional controls can help extend endpoint protection beyond conventional file-based antivirus scanning.

Endpoint Security Is One Layer

Security works best in layers.

Protecting employee computers does not replace the need to secure websites, email, domains, DNS, cloud services, networks, user accounts, or business data.

Likewise, website security does not protect an employee's computer from malicious software.

AmeriHost approaches endpoint security as one component of the larger technology environment.
